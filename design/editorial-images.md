# Редакционная библиотека изображений

Создано 22.10.2026 встроенным image_gen по запросу владельца. 10 самостоятельных генераций; исходные PNG остаются вне проекта в Codex generated_images. Перед включением в проект выполнено преобразование в WebP, 1200×800, quality=82, method=6 (Pillow). В runtime и Git добавлены только WebP.

Изображения переиспользуются по кругу: статья 1 → изображение 1, статья 11 → изображение 1. На стандартных 40 статьях каждый файл используется четырежды. Каталог: public/assets/images/editorial/.
