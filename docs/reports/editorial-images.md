# 10 постоянных WebP-изображений

22.10.2026, по прямому запросу владельца. Использован встроенный image_gen: 10 отдельных генераций без CLI/API-ключа. Полные промпты сохранены в design/editorial-images.md; исходные PNG остались в каталоге Codex вне проекта.

Перед добавлением в public все изображения преобразованы в WebP через Pillow: 1200×800, quality=82, method=6. Проверен реальный формат каждого файла. Всего 1 219 788 байт; от 62 344 до 275 132 байт на файл. В Git/runtime добавлены только 10 WebP в public/assets/images/editorial/.

SeedImages больше не генерирует SVG: он возвращает URL постоянного файла по кругу из десяти. BlogSeeder использует тот же каталог для новых записей. CLI bin/refresh-images.php обновляет только поле image у существующих статей через подготовленные запросы SeedRepository в транзакции. При обычном сиде прежние изображения сохраняются. --fresh не удаляет файлы библиотеки. Это изменение предыдущего требования о SVG по новому указанию владельца.

Обновление рабочей БД выполнено без --fresh: 40 статей получили новые пути. Каждый файл используется четырежды. SHA-256 остальных полей постов (включая views), категорий и связей до/после совпал: 9976a06c08f990c01a99447e2ce3ea1a4759395a287b49d40c04c69159c232e4. Второй refresh изменил 0 строк; обычный сид сохранил весь набор. Доказательство: var/image-library-checks.json, инструмент tools/check-image-library.php.

Проверки:

- docker compose up -d --build — успешно; WebP доступны обоим образам через COPY public, источник не зависит от uploads-тома.
- node tools/check-seed-assets.cjs — все 10 URL дают 200 и image/webp; RIFF/WEBP сигнатуры и байты HTTP совпадают с исходными файлами проекта.
- node tools/check-editorial-images.cjs — главная, категория, статья на 390 и 1440, все изображения реально декодируются в 1200×800, отсутствуют переполнение и browser pageerror. Чёрно-белый фильтр hero удалён, вычисленный filter=none. Снимки и checks.json в var/editorial-preview/.
- php -r 'ob_start(); require "tools/check-views.php";' — home/category/post/404: render, escaping, semantics OK; пагинатор сохраняет сортировку. Буфер нужен CLI-проверке с параллельно добавленной CSRF-сессией.
- php -l новых/изменённых PHP и npm run build:css — успешно.
